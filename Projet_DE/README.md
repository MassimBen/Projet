
# Projets data engineering

## 01 — Pipeline de données CNAM

Ce projet met en place un pipeline ELT avec Bruin et Google Cloud Platform. Il collecte des données de dépenses de santé CNAM ainsi que des données de comorbidités et de patientèle issues des sources officielles d’Assurance Maladie, puis les charge dans BigQuery.

Consultez la [description détaillée du projet](./01-cnam-health-pipeline/description_projet.md) et le [catalogue des jeux de données](./01-cnam-health-pipeline/catalogue_donnees.md). Le fichier [learning.md](../learning.md) retrace les erreurs rencontrées, leurs diagnostics et les solutions appliquées ou envisagées.
